## Use Case таблица (пользователи и сценарии)

**Пользователи:**
- Клиент (внешнее приложение)
- Администратор API Gateway
- Разработчик (читает документацию)

**Use Case сценарии:**
1. Клиент отправляет запрос -> Gateway маршрутизирует
2. Клиент получает 429 при превышении лимита
3. Администратор создаёт API-ключ
4. Администратор настраивает rate limit для клиента
5. Разработчик читает документацию на портале
6. Система логирует задержки и ошибки
